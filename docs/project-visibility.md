# 프로젝트 표출 제어 기능

## 개요

JSON 파일에서 프로젝트 데이터를 삭제하지 않고도 화면에 표출하지 않을 수 있는 기능입니다.

## 사용 방법

### 1. 프로젝트 숨기기

JSON 파일에서 해당 프로젝트에 `"visible": false` 속성을 추가합니다:

```json
{
  "id": "project-id",
  "name": "프로젝트 이름",
  // ... 기타 속성들
  "visible": false
}
```

### 2. 프로젝트 다시 표시

`visible` 속성을 `true`로 변경하거나 속성 자체를 제거합니다:

```json
{
  "id": "project-id", 
  "name": "프로젝트 이름",
  // ... 기타 속성들
  "visible": true
  // 또는 visible 속성을 아예 제거
}
```

### 3. 기본 동작

- `visible` 속성이 없는 프로젝트: **표시됨** (기본값)
- `"visible": true`: **표시됨**  
- `"visible": false`: **숨겨짐**

## 개발 모드에서 숨겨진 프로젝트 확인

개발 중에 숨겨진 프로젝트도 함께 확인하고 싶다면:

### 1. 환경변수 설정

`.env` 파일을 생성하고 다음을 추가:

```
VITE_SHOW_HIDDEN_PROJECTS=true
```

### 2. 시각적 표시

개발 모드에서 숨겨진 프로젝트는:
- 투명도가 낮아짐 (60%)
- 약간의 그레이스케일 효과 적용
- 우측 상단에 "숨김" 배지 표시

## 적용 범위

이 기능은 다음 데이터 소스에 모두 적용됩니다:

- `/public/data/projects.json` (포트폴리오 페이지)
- `/public/data/personal.json` (개인 프로젝트 페이지)

## 링크 대체 텍스트 기능

### 사용 방법

링크가 더 이상 작동하지 않을 때 (호스팅 만료, 사이트 폐쇄 등) URL은 보존하면서 대체 텍스트를 표시할 수 있습니다:

```json
{
  "links": [
    {
      "label": "Live",
      "url": "http://example.com/",
      "altText": "호스팅 만료"
    }
  ]
}
```

### 동작 방식

- `altText`가 **있으면**: 링크 버튼 대신 대체 텍스트가 표시됨 (클릭 불가능)
- `altText`가 **없으면**: 기존처럼 정상 링크 버튼 표시

### 시각적 표시

- 비활성 링크는 회색톤으로 표시
- 마우스 오버 시 효과 없음
- `cursor: not-allowed` 스타일 적용

## 장점

1. **데이터 보존**: 원본 데이터를 삭제하지 않고 임시로 숨길 수 있음
2. **쉬운 복구**: `visible` 속성만 변경하면 즉시 복구 가능  
3. **개발 편의성**: 개발 모드에서는 숨겨진 프로젝트도 확인 가능
4. **유연성**: 프로젝트별로 개별적으로 제어 가능
5. **링크 보존**: URL을 삭제하지 않고 대체 텍스트로 상황 설명 가능
